# 第五轮：官方 Fourier 主干、完整分辨率的 Path 配对实验

2026-11-11。结果产生前记录。仅本地材料；保留第三、四轮全部产物。

## 科学问题与边界

在原始 NeurOLight 12×64 Fourier 架构和 160×480 原始分辨率下，固定输入信息和训练协议后，将物理场输出改成 Path 包络并恢复相位，是否降低验证误差？主比较为 direct 与 path；两者均保留官方 exp wave prior，不把额外 prior 的有无混入比较。

只用原64训练、8验证几何，训练常数只用训练标签拟合。历史45个测试几何不做推理。结果是重复用于选择的验证集上的探索，不能视为独立泛化确认。独立新测试留待方法锁定。

## 固定架构与输入

原 GitHub commit 08cad10a78a01e4a522f8b4d287db0b363054e33；使用第四轮 AST 兼容加载器，保留原模型类体和 Fourier 算子。12层、通道64、modes(40,70)、head256、GELU、原卷积stem、FFN+depthwise卷积，aug_path=False（论文主模型）、dropout=.1、drop_path=0（避免未验证的旧timm替代影响）、不启用checkpoint。若显存无法容纳batch1，可在训练前记录对双方完全相同的执行调整。

双方接受与第四轮相同的10个实输入特征：归一化ε、二值src_mask、x、y、源x/y、方向、训练标定k、path/W、linear/W。原模型的复数输入接口仅用于无损打包：第0个复通道为 ε+0j，后续实特征逐对装入实/虚部，最后补零；共6个复通道、12个实通道，再附原始exp编码4通道。stem输入16实通道。ε的虚部恒零，避免把源掩膜当作复介电常数。输入stem通道增加，其他架构不变；这是相同输入条件下的骨干适配，不是原生已知入射复场任务复现。

λ=1.55μm，dx=dy=.05μm。所有输入、wave prior、输出、监督均为160×480；不做降采样或输出插值。modes40/70保持固定物理域的频率截断，不机械按分辨率翻倍。

direct直接输出E；path输出A后乘exp(i·k·path)得到E。相同原分辨率物理复场相对MSE损失，相同验证RelL2；不使用任何标签相位对齐。Path载波只取几何/源/训练标定常数。

## 训练与选择规则

先做不查看验证结果的显存/吞吐检查，选择双方相同的可运行物理batch与精度；优先batch2、FP32，若bfloat16 autocast兼容且明显降低资源可在训练前固定为双方同一模式。FFT仍保持complex64，不改写核心算子。最终选择和依据写入preflight.json，随后冻结manifest。

主实验每次1200次更新；学习率候选[0.0005,0.001,0.002]，AdamW weight_decay=1e-4，余弦衰减至初始5%，梯度裁剪5，无额外增强。每方法seed2026各3候选，按8验证平均逐样本RelL2选lr；每50步验证选checkpoint（含第1步），同一验证机会。选定lr再做seed2027/2028，共6次搜索+4次重复=10次训练。同种子固定初始化与批次抽样顺序。批量以preflight冻结记录为准，两者一致。

每种子共享初始权重哈希和批次序列；记录参数元素数与实自由度、训练时间、显存、所有验证曲线、检查点。搜索机会和更新次数相同，报告实际GPU时间，不声称完全等时。不根据结果追加候选或剔除不利种子。若Path不改善，照实报告。

额外说明：本实验回答完整分辨率与此架构下的表示收益，不等于已优化完原生cMAE+TV、源复场和叠加增强。有限1200步不能排除收敛速度/优化难度因素。
