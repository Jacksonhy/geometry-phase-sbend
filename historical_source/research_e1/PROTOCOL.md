# E1：完整分辨率 Fourier 表示消融

2026-11-12，新增结果产生前记录。

目标：区分一般相位解调收益与弧长相对于直线载波的独立贡献。Direct / Linear / Path 均使用第五轮原样架构与 wave prior，共享10个基础输入（含两种距离与训练标定k），160×480，不做输入降采样或输出插值。

主比较为 Path 对 Linear；Direct 对 Linear 和 Direct 对 Path 为辅助。只在原64训练与8验证上开展，不访问新测试场或历史测试推理，不启动E2/E3。

复用research_v5所有10个已冻结Direct/Path训练，先核验原代码、数据和权重哈希。Linear只把输出载波改为 exp(i*k*linear_distance)，k、源方向和线距与第三、四轮一致；网络直接输出包络，恢复物理复场后计算相同相对MSE。所有方法接收相同几何输入，Linear组仍保留path/W输入。

不改写或覆盖第五轮代码。通过独立包装调用其原train_one；只将forward中linear分支送入相同的载波乘法，并为该运行传入直线载波；输出目录独立。核验相同种子的初始权重、完整批次序列、标定与归一化完全一致。

Linear学习率候选[0.0005,0.001,0.002]，搜索种子2026，按8验证平均RelL2的最佳检查点选lr，再重复2027/2028，共新增5次训练。每次1200更新、FP32允许TF32、batch2、AdamW wd1e-4、余弦到初始5%、梯度裁剪5、dropout0.1、drop_path0，无增强。每50步验证，含第1步，与原运行一致。不根据结果添加候选或改训练预算。

报告三种子均值±样本标准差、配对种子差、逐几何差、幅度与相位诊断、学习率搜索完整表、曲线、耗时与显存。补充相同lr/seed的Linear-Path比较，避免忽略选定lr不同的影响。只给探索性验证结论；8验证几何已经重复用于开发和选择，不能称为独立确认或统计显著性。

如果Linear与Path相近或优于Path，如实限制路径贡献。即使Path继续明显优于Direct，也不能用此辅助差值替代Path-Linear的核心结果。
