# S-bend optical audit protocol
Retrospective existing test100; seeds42,2026,2027; Linear/ArcOnly/LocalTangent/v2, validation-best primary, last sensitivity. Reuse saved physical-field predictions, preserve all sources and hashes. Exact historical directional FD extractor, no refit. Replay coefficients from predictions and compare historical CSV. Label audit all180: native S equals outgoing alpha/incoming alpha with known directions; source plane and modal labels replay.
Three comparisons: model pred_proxy-truth_proxy; extractor truth_proxy-native; total pred_proxy-native. Complex differences additive, absolute/power/phase metrics not additive. T/R=|coefficient|², IL=-10log10(T), floor1e-12 disclosed; phase gate fixed native amplitude>=.05, no target alignment. Per seed/per geometry/per port metrics, paired geometry bootstrap5000, crossseed mean/SD separate. No pooling 300 as independent. Train/val native distributions for task feasibility; test retrospective only. No design selection, no retraining. Historical Ez-only extractor is proxy; report bias including reflection. Native E/H labels do not imply a full E/H predictor.
