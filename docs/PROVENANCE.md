## Code

The main portable numerical functions originate from the original geometry, Path v2, common-feature, network, and local-phase experiment code. `source_provenance.json` records source names, source SHA-256, publication SHA-256, and adaptation notes. Source paths are expressed relative to the archived research collection, not as dependencies on that collection.

Portable adaptations change imports, checkout-relative paths, device/seed arguments, and command-line orchestration. Original NeurOLight class bodies and the core numerical geometry/metric functions are retained. The compatibility harness supplies dependency names and limited replacements under the exercised GELU/zero-stochastic-depth configuration. The main package never imports the historical research root.

`historical_source/` retains the original experimental programs for sampling, calibration, FDTD generation, model comparison, optical postprocessing, high-resolution diagnostics, timing, and exploratory Y-branch analysis. These scripts retain historical absolute paths and inter-experiment imports. They are an archive, not all independently portable commands. `configs/historical_formal.json` describes an earlier five-method stage and must not be confused with the final four-method checkpoint list. Earlier direct/Path-v1 comparisons are historical context; only the 12 explicitly listed best checkpoints are distributed.

## What can be reproduced directly

- Primary-resolution S-bend field and local-phase metrics from the 12 frozen checkpoints and supplied 288 field files.
- Fresh geometry-only material initialization and neural inference for supported Euler parameters and the supplied sinusoidal family.
- Fresh main-comparison training on the fixed 64/16 split, with the frozen training-only calibration.
- Arithmetic checks on archived seed summaries, comparisons, and timing ledgers.
- English PDF generation from the current Markdown and existing images.

## Limits

- Full original field caches, optimizer states, last checkpoints, and all exploratory model weights are not distributed.
- High-resolution Euler/sinusoidal raw field sets, straight-reference raw fields, and full Y-branch raw data are not packaged. Their source programs and result tables are archived. Repeating those diagnostics requires obtaining/regenerating the original inputs and adapting the historical layout.
- The compact training CLI starts a fresh run; it does not implement historical optimizer resume. A short training smoke run is not a repetition of all 12 complete training runs.
- Historical figures, grid studies, FDTD timing, bootstrap tables, and optical postprocessing are not all regenerated by `evaluate.py`. Existing figures are the manuscript's original images.
- Different hardware, numerical libraries, and CUDA builds may prevent bitwise equality. Manuscript workflow timings are measurements from the documented historical hardware, not performance guarantees for a new checkout.
- The package provides primary-resolution reproducibility, not a new claim of continuum-converged electromagnetic accuracy or generalization to arbitrary device topologies.
